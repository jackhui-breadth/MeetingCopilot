# Changelog

## 0.1.0 - Developer Preview

- Native macOS recording with real-time gain, compression, limiter, and AAC output
- Local transcription with Fun-ASR Nano, SenseVoice, and MLX Whisper backends
- Local cam++ speaker clustering with optional expected speaker count
- Editable timestamped transcripts, playback highlighting, and participant naming
- Local Ollama minutes generation with long-transcript chunking and templates
- Action-item extraction and macOS Reminders sync
- Audio/video import, TXT export, rename, delete, and crash-state recovery
